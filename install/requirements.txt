# =============================================================================
# Multi-hop-Reasoning-VLM-Agent  —  Main environment (game-ai-agent)
# Python 3.11 | torch 2.11.0+cu130 (pulled by vLLM 0.20) | CUDA 12.8+ / 13.x
#
# This file installs the unified training + inference + game-environment
# stack. After install, the env contains:
#   * GRPO + FSDP + LoRA training on Qwen3.5-9B
#   * vLLM 0.20 inference server (Qwen3.5-9B + Qwen3.5-35B-A3B)
#   * Skill bank pipeline + RAG (Qwen3-Embedding-0.6B)
#   * Baselines (OpenAI, Anthropic, Google, Together, Z.AI, xAI)
#   * GamingAgent / LMGame-Bench (2048, plain Tetris)
#   * gym-v (179 visual envs incl. 13 Temporal/* Sega Genesis games)
#   * Avalon (PYTHONPATH), Diplomacy
#   * visual_reasoning_wrapper benchmark loaders (TIR-Bench, VisualToolBench,
#     Video-Holmes, SIV-Bench) — heavy grounding heads (Florence-2 /
#     GroundingDINO / OmniParser-v2 / EasyOCR) live in vlm_benchmarks env.
#
# Install:
#   pip install -r install/requirements.txt
# (install_main_env.sh runs this for you and also editable-installs
# GamingAgent and gym-v.)
#
# Excluded / requires separate env:
#   * Candy Crush — `tile_match_gym` pulls in `numba` which forces
#     numpy<2 and breaks the Qwen3.5/vLLM stack. Use a SubprocessEnv
#     or a dedicated env if you need it.
#   * Super Mario — `nes-py` requires numpy<2 + gym==0.26.2.
#     Install via install_orak_mario.sh (env: orak-mario).
#   * BrowserGym (playwright==1.44 hard-pin) → env: browsergym.
#   * OSWorld     (gymnasium~=0.28, transformers~=4.35) → env: osworld.
# =============================================================================

# ── Core ────────────────────────────────────────────────────────────────────

# warning is benign; do NOT downgrade or you will break torch 2.11.)
