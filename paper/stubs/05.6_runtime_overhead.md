# §5.6 — Runtime overhead and component breakdown

> **Reviewer ask** (NeurIPS 2026 R1): "every figure tracks reward, no
> figure tracks compute.  How much extra wall and tokens does the
> Bank Agent + Harness add over a plain LoRA actor?"

Source: `runtime_log/component_timings.jsonl` — one row per
*(trainer step, component)* pair.  Components observed:

| component                | side                | meaning |
| ------------------------ | ------------------- | ------- |
| `actor.action_taking`    | actor LoRA          | per-step low-level action call |
| `actor.skill_selection`  | actor LoRA          | per-step skill ranking call |
| `actor.intention`        | actor LoRA          | per-step intention update |
| `actor.contract`         | actor LoRA          | (rare) binding-contract emitter |
| `crafter.deterministic`  | rule-based crafter  | mutation-engine wall (no LLM) |
| `crafter.llm`            | 35B / API           | crafter free-form proposal call |
| `promotion.judge`        | 35B / API           | promotion-gate LLM judge |
| `harness.validator`      | 35B / API           | LLM second-pass harness validator |
| `schema.profile`         | 35B / API           | game-schema profile generation |

Generator: `python -m scripts.skillbridge_analysis.plot_runtime_overhead --run-dir <run-dir>`.

The summary JSON (`runtime_overhead_summary.json`) reports per
component:

* `n_calls`
* `total_ms`, `ms_per_call`
* `prompt_tokens`, `completion_tokens`, `*_per_call`
* `pct_of_total_ms`

The bar chart (`runtime_overhead_bar.png`) stacks total wall (top
panel) and total tokens (bottom panel) so the reader can immediately
read off "what fraction of the run is the Bank Agent costing me?"

We also compute a "Bank Agent overhead ratio" = `(crafter.* +
promotion.judge + harness.validator + schema.profile) / actor.*`,
which is the headline number for the §5.6 paragraph.
